## Mandatory Coding Standards

Before creating or modifying code, read and follow `CODE_RULES.md`.

Every code change must include appropriate automated tests. Run the
relevant tests, linting, type checks, and build checks where configured.
Follow the repository's SonarQube rules and security requirements.

Never claim that a check passed unless it was actually executed.
Report all failures, skipped checks, and unresolved issues honestly.
